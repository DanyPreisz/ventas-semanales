# Predicción de Ventas Semanales

Proyecto de regresión / series de tiempo listo para Google Colab. Incluye EDA, lags, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/ventas-semanales/blob/main/ventas_semanales_colab.ipynb)

## Contenido

- Serie de ventas semanales simulada (tendencia + estacionalidad + ruido)
- Features: lags, media móvil, promo, feriado
- EDA (plot de serie, boxplot, scatter)
- Modelos: Ridge, Random Forest, Gradient Boosting
- Feature importance
- **SHAP** (summary plot)
- Conclusiones

Datos: simulados

Rango esperado (ejemplo): R² > 0.80
